# Task 1: Analyze PRD vs Specification Differences

## Learning Objective
Understand the fundamental distinction between PRDs (persistent business documentation) and Specifications (temporary implementation guides).

## What You'll Analyze

Two real Task Master documents for **Task Comments**:
- `docs/prds/task-comments-v1.0.md` - The PRD
- `specs/task-comments/specification.md` - The Specification

## Your Task

Compare these documents across 6 dimensions:
1. **Content** - What's in each document?
2. **Audience** - Who reads each and why?
3. **Lifecycle** - Why persist vs archive?
4. **Detail** - How specific is each?
5. **Integration** - How do they reference existing code?
6. **Value** - Which document would you keep forever?

## Success Criteria

✅ Identified specific content differences  
✅ Analyzed audience needs for each document  
✅ Explained persistence vs archival rationale  
✅ Compared specificity levels with examples  
✅ Analyzed integration context patterns  
✅ Answered key question with reasoning  
✅ Summarized key learnings

## Time Estimate
15-20 minutes

## Key Question

"If I could only keep ONE document forever (PRD or Spec), which should it be and why?"

Your answer will reveal whether you understand the fundamental distinction!

## Getting Started

1. Open both documents side-by-side
2. Read through each completely
3. Compare section-by-section
4. Fill out analysis template
5. Answer the key question with reasoning
